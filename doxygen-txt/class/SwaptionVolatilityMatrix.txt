SwaptionVolatilityMatrix
 -- |At-the-money swaption-volatility matrix.
 -- |This class provides the at-the-money volatility for a given swaption by interpolating a volatility matrix whose elements are the market volatilities of a set of swaption with given option date and swapLength.The volatility matrix M must be defined so that: the number of rows equals the number of option dates;the number of columns equals the number of swap tenors;M[i][j] contains the volatility corresponding to the i-th option and j-th tenor.
